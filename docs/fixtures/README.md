# Fixtures

Named fixtures. Each file is walls, thickness, hole positions, thread — the
facts needed to make something that bolts to it. Nothing about how it was made.

When the operator names a fixture, read its file here.

Setup records — how a blank was actually held for one job, measured and dated —
also live here and are a different thing. See
[SETUP-RECORD-SCHEMA.md](SETUP-RECORD-SCHEMA.md). `safety/machining-rules.md` R2
refuses a program whose workholding has no such record.
